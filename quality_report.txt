- chroma_db/: persistent ChromaDB files (ignored by .gitignore)
- rag_web/: local virtualenv (ignored by .gitignore)

Key Design/Implementation Notes
- Parsing
  - Strengths: best-effort extraction with strong defaults; polite crawling support (sitemap preference + delay); outputs include URL/title/extractor/fetch timestamp.
  - Limitations: JS-rendered sites may require a browser fetcher (Playwright) to render content.
- Chunking
  - Strengths: deterministic IDs; metadata includes chunk offsets and page metadata; JSONL output is Chroma ingestion-friendly.
  - Limitations: character-based chunking can cut sentences; for higher quality retrieval consider sentence/paragraph-aware splitting.
- Embeddings + Chroma
  - Strengths: persistent store; skips already-ingested ids; cosine space configured.
  - Limitation: sentence-transformers model download requires network unless already cached; offline mode supported by --local-files-only.
- Generation
  - Strengths: prompt templating in YAML; history persisted per session; supports Ollama + OpenAI-compatible endpoints.
  - Current behavior: config defaults to OpenAI-compatible provider; requires OPENAI_API_KEY in environment (or .env if python-dotenv is installed).

Repro / Runbook (Happy Path)
1) Parse (single page)
   - python parsing/parse_website.py "https://example.com" --out parsing/parsed_results.txt
2) Chunk
   - python chunking/chunk_text.py --in parsing/parsed_results.txt --out chunking/chunks.jsonl --chunk-size 1000 --overlap 100
3) Ingest to Chroma (using rag_web env)
   - rag_web/bin/python embeddings/ingest_chroma.py --in chunking/chunks.jsonl --persist-dir chroma_db --collection rag_chunks --model sentence-transformers/all-MiniLM-L6-v2 --local-files-only
4) Chat
   - If using OpenAI-compatible:
     - Put OPENAI_API_KEY in .env (and ensure python-dotenv is installed), then:
       - rag_web/bin/python generation/chat_rag.py --query "..." --session demo --local-files-only
   - If using Ollama:
     - Set llm.provider: "ollama" in generation/config.yaml and run an Ollama server.
